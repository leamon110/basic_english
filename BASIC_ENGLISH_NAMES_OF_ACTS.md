# Basic English：动作表达研究索引——Names of Acts 与 Some Common Needs

> 本文是项目的跨章节研究索引，不是 Ogden 原书中某一章的完整转录。必须区分两部分：
> - **Names of Acts（《The ABC》pp.162–186）**：原书逐个讨论 BE、COME、DO 等核心 Operators 的用法和意义，详见 \`BASIC_ENGLISH_OPERATORS.md\`。
> - **Some Common Needs（《The ABC》pp.242–262）**：原书在 A Basic Selection 下列出 Simple Acts、Complex Acts、Other Suggestions，给出常见动作和其他意思的 Basic 表达。
>
> 本文后续的动作分类表主要整理第二部分 Some Common Needs，并与 Names of Acts 的 Operator 用法交叉对照。项目新增的结构归类与练习说明，不应误称为原书的章节结构。

> **范围补充：** Some Common Needs 只是 A Basic Selection 的第一部分；原书随后还有 Words Formed by Endings（pp.262–264）和 The Most Necessary Fixed Word-Groups（pp.264–269）。本文主要整理动作与常见意思的表达，不代表这三部分均已完整收录。

## 1. 为什么必须区分这两个相邻部分

Ogden 在《The ABC of Basic English》中先于 Expansions 部分安排 “Names of Acts”，逐个讨论 Operators；随后在 A Basic Selection 中安排 “Some Common Needs”，分为：
- Simple Acts
- Complex Acts
- Other Suggestions

原作者在 Some Common Needs 开头明确说明：要熟练使用 Basic，必须掌握如何用850词覆盖那些不在850词表中的常见动作和事物；这些常见问题是经过长期使用经验整理出来的实际答案。

这直接说明：
- 850词表本身不是一张普通英语动词的一对一替换表；
- 需要学习常见动作的 Basic 表达方式；
- 普通英语同一个动词，语境不同，Basic 表达可能完全不同；
- 这些表达会调用 Operators、Directives、Things、Qualities、Names of Acts 和固定词组等不同单位。原书中的 something 等构式也不一定作为850个基础词条逐项列出；项目 validator.js 对原书明确教授的若干构式作了单独允许。

## 2. Simple Acts：简单的身体动作和日常行为

### 2.1 说话、讲述、唱歌、听和读写

| 普通英语动作 | Ogden 给出的 Basic 表达 | 结构观察 |
|---|---|---|
| speak to a person | say something to him | Operator + 内容名称 + 接受者关系 |
| speak at a meeting | give a talk；make a statement | Operator + Names of Acts |
| speak a language | have a knowledge of it | have + Name of Act + of |
| tell a story | give it | give + 对象 |
| tell someone how to do something | give directions | Operator + Name of Act |
| “as I was telling you” | “as I was saying” | 依上下文选择 say |
| sing | give a song | Operator + Name of Act |
| hear music | the music comes to the ears | come + to + 身体部位 |
| listen | give it their attention | Operator + Name of Act |
| hear an account later | have news of it | have + Name of Act + of |
| write about something | put his views into writing；put them down on paper | put + Name + Directive / 方向副词 |
| read about something in a newspaper | see it in the paper；read it；go through it with care | see / read / go through，依阅读动作和语境选择 |
| send a letter to a newspaper | send a letter to the paper | send + 对象 + 目标 |

**最重要的观察：speak 不是一个固定替换答案。**

- 对某个人说话：say something to him；
- 在会议上发表讲话：give a talk / make a statement；
- 掌握一种语言：have a knowledge of it。

必须先判断普通英语动词在当前句子中的实际意思。

### 2.2 吃、咬和吐

| 普通英语动作 | Ogden 给出的 Basic 表达 | 结构观察 |
|---|---|---|
| eat | take food；have a meal | take / have + 名称 |
| eat more than one can contain | be unable to get through it | get through 表示把食物吃完 |
| bite a piece | have a bite of it / at it | have + 名称 + 关系词 |
| bite off a piece | have a bite of it | 用 bite 这个动作名词表达 |
| spit food out | put it out of your mouth | put + out + of + 身体部位 |

### 2.3 触碰、击打、抓挠、切割和破坏

| 普通英语动作 | Ogden 给出的 Basic 表达 | 结构观察 |
|---|---|---|
| touch something | put a hand / finger / another part of the body on it；give it a touch | put + 身体部位 + on；或 give + 名称 |
| touch something by chance | come up against it | come + up + against |
| hit something hard | give it a blow | give + 名称 |
| scratch something with a pointed object | make a mark on it | make + 名称 + on |
| scratch an insect bite | give it a rub | give + 名称 |
| scratch deeply | get one's nails into it | get + 身体部位 + into |
| cut a person | give the person a cut | give + 名称 |
| cut through thread or cake | get it cut | get + 宾语 + 过去分词形式 |
| break a thread | the thread is broken；get it broken | be / get + 过去分词 |
| smash a plate | the plate may be smashed | 被动/结果状态 |
| a plate breaks by itself | it comes to bits | come + to + 结果名称 |

### 2.4 投掷、接住、拿住、移动和身体姿势

| 普通英语动作 | Ogden 给出的 Basic 表达 | 结构观察 |
|---|---|---|
| throw a ball to a baby | send the ball to a baby | send + 对象 + to |
| throw a ball over a wall / across a river | send the ball over the wall / across the river | send + 路径 Directive |
| throw someone off balance | put / throw someone off balance | put + off + 名称 |
| a sufficiently hard blow pushes someone against a table | the blow will send us violently against the table | send + against |
| catch a ball | get it in the hand | get + 对象 + 位置 |
| hold a ball | get a grip of it；keep it；have it in the hand | get / keep / have + 名称 |
| bring delicate things such as eggs | take them；come with them | take 或 come with，依说话视角和动作关系选择 |
| lie on something | be on it；rest on it | be / rest + on |
| stand up from lying down | get up | get + up |
| sit | take a seat；be seated | take + 名称 / be + 过去分词 |
| run quickly | go quickly | go + 方式副词 |
| run for health | take a run | take + 名称 |
| run away from danger | go (off) at a run | go + 方向/方式表达 |
| slip | have a slip；have a fall | have + 动作名称 |

原书还举出：
- 把手臂从衣服中伸出：take your arm out of your coat；
- 把钱放进口袋：put money into your pocket；
- 快速走出房子：go quickly out of the house。

这说明同一组基础单位可以组合出很多动作表达，但必须看清对象、路径、动作方式和结果。

## 3. Complex Acts：复杂动作，尤其是心理活动

### 3.1 思考、判断与知道

| 普通英语动作/意思 | Ogden 给出的 Basic 表达 | 结构观察 |
|---|---|---|
| think | give thought to；be in thought | give + 名称 / be + in + 名称 |
| think that something is so | be of the opinion；take the view that | be + of + 名称 / take + 名称 + 从句 |
| know that something is so | be certain of it；be conscious of it | be + Quality + of |
| know other facts | have knowledge or experience of them | have + 名称 + of |
| understand what one knows | be clear about it；have a grip of it | be + Quality + about / have + 名称 + of |
| understand horses | have a good knowledge of them | have + 名称 + of |
| understand a friend | see his point of view | see + 名称 + of |
| understand an argument | see the point of the argument | see + 名称 + of |
| mean something | have the sense of it | have + 名称 + of |
| remember | have a memory of it；keep it in mind | have + 名称 + of / keep + in + 名称 |
| forget | put it out of the mind；have no memory of it | put + out of + 名称 / have + 名称 + of |

| feel a wall to test whether it is dry | put one's hands on it | put + 身体部位 + on |

## 5. Other Suggestions：不只是动作动词

Ogden 的第三部分还处理：
- can、ought、shall 的表达；
- each、altogether、whole、few、many、too、once 等数量和程度；
- ago、already、yet、since、next、always 等时间表达；
- busy、deaf 等不容易直接进入 Basic 的性质词；
- world、life、hill、home、address 等普通名词的不同语境意义。

例如：
- can → be able to / it is possible for someone to；
- ought → it is right (wise) for someone to / it is someone's business to；
- shall（陈述句）→ will；“Shall I do it?” → “Am I going to do it or not?” / “Am I wise to do it?”；
- unless → if ... not；
- busy → is working hard / has much to do；
- deaf → whose hearing is bad；
- world（空间）→ earth；“the whole world is shocked” → every one；其他语境也可用 things / conditions；
- home → a place where one is living；在某些语境中还涉及 with one's family。

## 6. 从原书例子归纳出的表达模式

以下是本项目为教学整理的结构分类，不是声称 Ogden 原书只使用这些固定公式。

| 结构 | 原书例子 | 典型用途 |
|---|---|---|
| Operator + Directive | go into；come across；put out of | 动作方向、路径、状态关系 |
| Operator + Name | give a talk；make a statement；take food；make a start | 用动作/事物名称表达动作 |
| Operator + Name + Directive | have knowledge of；give signs of；put views into writing | 动作、状态与对象关系 |
| Operator + Quality | get taller；be clear；get ready | 状态或性质变化 |
| Operator + Object + Directive | put a hand on it；send a ball across the river；get facts into one's head | 对象在动作中的位置或路径 |
| Operator + Clause | see that ...；take the view that ...；have a feeling that ... | 观点、判断和复杂意思 |
| Name of Act + Directive | a taste for；a desire for；a grip of；a memory of | 用动作/状态名称加关系词表达 |
| 固定词组 | get on well；put up with；take into account | 不能只靠单词字面义推导的特殊用法 |


这些结构在不同主题中会反复出现，因此它们是可复用的表达工具，不是必须各自成为一课的分类。反过来，同一个普通英语词也可能因语境而换结构：speak、run、touch 都有不同用法。课程应把这种意义差异放在真实语境中对比。

这些归纳只帮助看清结构，不表示任意 Operator、Name 和 Directive 都能自由组合。固定词组仍须按原书清单核实，不能把“结构看起来相似”当成搭配正确的证明。


## 7. 这对课程意味着什么

Common Needs 的教学不能做成“普通动词 = 一个 Basic 短语”的背诵表。每个主题只需把四件事讲清楚：

1. 这个词在当前语境里具体是什么意思？
2. Basic 用什么结构表达这个意思？
3. 其他看似相近的表达，为什么不能在这里随意替换？
4. 学习者能不能把一个新例子说成 Basic，并从 Basic 句子反向理解？

同一个普通英语词在不同语境中可以对应不同结构；同一种 Basic 结构也会出现在不同意思的表达里。教学要让学习者看见这些联系，但不能把归纳出来的结构当成任意套用的万能公式。


## 8. 与当前 App 的关系

当前 App 已有一些基础规则题和句子练习，但还没有把 Operators 的基础知识与 Some Common Needs 的实际表达训练连成完整、自然的应用过程。

尤其需要避免：
- 把所有普通动词都塞进 Operator + Directive；
- 把原书的 Names of Acts 章节与 Some Common Needs 混成同一组内容；
- 把 get ready 误分类为 Operator + Directive（它是 Operator + Quality）；
- 把 get knowledge of 误分类为 Operator + Directive（它是 Operator + Name + of）；
- 把 talk about 误分类为 Operator + Directive（talk 是 Name of Act，talk about 是 Name of Act + Directive）；
- 让学习者只背替换答案，而不判断原句的语境。
