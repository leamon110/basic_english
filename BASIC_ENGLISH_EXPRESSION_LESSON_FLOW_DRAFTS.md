# Expression System — Module 1 Lesson Flow Drafts

> Status: first teaching-flow prototypes for the three Module 1 candidates in v0.3. These are curriculum drafts, not App screens, final lesson scripts or final acceptance. The aim is to test whether each candidate can be taught naturally without turning every source example into a separate rule.

## Module 1 — Understanding Basic Word Meanings

Shared learner method:

1. Start with a familiar root meaning.
2. Look at a real context where the word is used differently.
3. Identify the source-supported connection or the narrowing caused by context.
4. Use that connection to understand a new example.
5. Check that the learner is not inventing an unsupported meaning.

The three Lessons use the same broad method, but they answer different questions:
- C13: What related thing can this Name refer to?
- C14: How can a Quality word extend, or function as a Name?
- C15: Which narrower thing does the context mean?

---

## C13 — Names of Things: Meaning Expansion

### Teaching objective

The learner understands that a Basic Name can be used for another thing when the source recognizes a real connection between the root meaning and the new referent. The learner should be able to explain the connection, not merely memorize a second translation.

### Proposed teaching flow

#### 1. Start from familiar body-part meanings

Use a small set of concrete anchors:

- head → a rounded/top part;
- foot → a bottom or supporting part;
- mouth → an opening;
- neck → a narrow connecting part.

Show the root meaning and the related object-part meaning side by side. Ask what the two uses have in common: position, shape or structural role.

Do not start by presenting all eleven body-part examples as a vocabulary list. Four anchors are enough to reveal the idea; the remaining source examples can be used for practice/reference.

#### 2. Compare other kinds of connection

After the learner understands that the connection need not be literal identity, introduce three broader groups:

- **What it looks/sounds/feels like:** size, shape, surface, sound and other sensory similarities.
- **What it does or is used for:** function, behavior, action or result.
- **What it is connected with:** cause, process, use, part/whole, material/object and other source-listed relations.

Use only a few examples in the main explanation. Keep the complete source examples in a reference table so the lesson does not become a long catalogue.

#### 3. Move from visible things to less visible meanings

Introduce the source's “as if” examples after the concrete ones. Explain that a word can be used for an abstract thing by borrowing a familiar relation, even when no physical object is present.

The point is not “anything can be called anything”. The learner must be able to identify a relation that the source actually recognizes.

#### 4. Guided practice

Use three different task types:

1. **Recognize:** choose the root meaning that explains a related use.
2. **Explain:** select the connection — shape/position, sensory quality, function/behavior, cause/process, part/whole, material/object or “as if”.
3. **Transfer:** read a new source-listed example and explain why the Name can be used there.

Include one contrast item where two things merely remind the learner of each other but the source does not establish an accepted expansion. The correct response should be “not established by this rule”, not a guessed connection.

#### 5. Reverse check

Give the expanded use and ask what the word refers to in that context. The learner must recover the intended thing, not simply repeat the root definition.

### Scope controls

- This Lesson teaches Names of Things, not Names of Qualities.
- It does not teach Special Use / meaning narrowing; that is C15.
- It does not teach the 250 Fixed Word-Groups; idiomatic combinations are a separate source section.
- It does not teach -er/-ing/-ed derivation; word-form rules remain in the foundation.
- The full source relation list is reference material. The lesson body should use representative examples, not one mini-rule for every item.

### Lesson-size test

**Current judgment:** one Lesson with three teaching sections is still viable. The source material is broad, but the learner performs one repeated operation: identify a source-supported relation from root Name to related referent.

**Reopen the boundary only if** the authored practice becomes so large that the learner is forced to memorize unrelated relation categories without seeing the shared operation. Do not split merely to give each relation a separate Lesson.

## C14 — Names of Qualities: Meaning Expansion & Use as Things

### Teaching objective

The learner recognizes two related but distinct uses of Quality words:

1. a Quality extends from its root property to a related experience or response;
2. a Quality word can function as a Name of Things in the source-listed cases.

These two uses must remain visibly separate inside the Lesson.

### Proposed teaching flow

#### 1. Begin with literal Quality meanings

Use familiar pairs from the source:

- bitter as a taste → bitter as an experience;
- cold as temperature → cold as a look;
- smooth as a surface → smooth as words;
- bright as a colour → bright as a face.

Ask what changed and what stayed connected. The learner should notice the move from a physical property to a person's experience or response.

#### 2. Add associated-property extensions

Use cheap and simple to show a different relation: one property is extended to a quality or judgment commonly associated with it.

State the limit clearly: association is not identity or a logical guarantee. A cheap object is not necessarily poor in every respect; the source is describing a recognized use, not a universal fact.

#### 3. Introduce Quality words used as Names of Things

Explain the function change with a small number of source-listed examples first. Then show the full source list as a reference group:

acid, chief, chemical, cold, complex, cut, elastic, equal, fat, female, first, flat, future, good(s), hollow, last, living, male, natural, opposite, parallel, past, present, public, quiet, right, safe, same, second, secret, solid, sweet, waiting, wrong, young, plus colour names.

Preserve the source restriction: dark, first, last, quiet and same occur only with “the”.

Do not teach this as “any adjective can become a noun”. It is a bounded source-listed use.

#### 4. Guided practice

Use two clearly labelled practice groups:

- **Meaning extension:** decide which related experience/property is being described.
- **Quality used as a Name:** decide whether the word is naming a thing/class or describing a property; apply the source's “the” restriction where specified.

Do not mix both task types in one question before the learner has seen the distinction.

#### 5. Reverse check

Give a contextual sentence and ask:
- Is the Quality literal or extended?
- Is it describing something, or functioning as a Name?
- What does it refer to in this context?

### Scope controls

- Do not repeat C13's Names of Things examples.
- Do not teach Special Use / narrowing here; that is C15.
- Do not imply all modern English adjective-to-noun conversions are valid Basic uses.
- Do not mix the Quality-as-Thing list with plural/word-form rules unless a specific example requires the foundation reminder.

### Lesson-size test

**Current judgment:** one Lesson with two explicit parts is viable. The Quality-extension examples are few, but the source-listed Quality-as-Thing group supplies substantial practice. Splitting by word-class function would create two very small Lessons; keeping the parts together makes the semantic/function range of Qualities visible without pretending they are the same rule.

## C15 — Special Use: Meaning Narrowing

### Teaching objective

The learner distinguishes meaning narrowing from meaning expansion and uses context to identify which more specific referent is intended.

### Proposed teaching flow

#### 1. Contrast expansion and narrowing

Use one simple pair:

- Expansion: a word's use reaches a related referent beyond its root use.
- Special Use: a broad word is restricted by context to a particular object, member or sense.

Do not introduce all examples before this contrast is clear.

#### 2. Teach the three source patterns

- **Material name → particular object:** card, chalk, cloth, paper.
- **Broad class → important subclass:** shoes/boots; watches/clocks.
- **Context selects an expected sense:** ball, business man, judge, man, pictures.

The learner should identify what the broader category is and what narrower item the context selects.

#### 3. Add the warning example

Use curtain to show that a special use is not automatically the most common use. Context matters; the lesson must not turn one special sense into the word's universal definition.

#### 4. Guided practice

For each item:
1. show the broad/root category;
2. provide a short context;
3. ask what specific object/person/class is intended;
4. ask which part of the context supports that choice.

Include a contrast where the context does not justify narrowing; the learner should retain the broader meaning rather than guess.

#### 5. Reverse check

Give the narrow referent and ask what broader Name it belongs to. Then give a different context and ask whether the same narrow sense still applies.

### Scope controls

- C15 is not the same as C13 expansion.
- C15 is not the same as C14 Quality words functioning as Names of Things.
- C15 is not the 250 Fixed Word-Groups chapter's idiomatic/special combinations.
- Do not present a contextual special use as the only or most common meaning of the word.

### Lesson-size test

**Current judgment:** one focused Lesson is justified. It has three source-backed patterns and a distinct decision: context narrows a broader meaning. It should not be merged with C13/C14 simply because all three concern word meaning.

## Module 2 — Expressing Common Meanings in Basic English

Shared method: ordinary-English word → identify its meaning in this context → build or select a Basic expression → reverse-check that the intended meaning remains.

## C01 — Communication & Information

### Teaching objective

The learner stops treating an ordinary communication verb as a one-to-one vocabulary replacement. The learner identifies the communication event: who is expressing or receiving what, through which action, and to whom.

### Proposed teaching flow

#### 1. Reuse and extend the existing speak prototype

Keep the existing three-way contrast:

- speaking to a person;
- speaking at a meeting;
- speaking a language.

The first two are communication acts; the third is knowledge of a language. Make the distinction visible rather than adding a fourth rule.

The existing App prototype is reused and expanded; its current three-question quiz is not copied unchanged.

#### 2. Organize the remaining examples by communication role

- **Expressing / delivering information:** tell a story; give directions; sing; make a statement.
- **Receiving information:** hear music; listen with attention; hear news later.
- **Written information:** put views into writing / down on paper; read or see something in a newspaper; send a letter to the paper.

The learner should notice that Basic may describe the same event through an Operator plus a Name (give a talk, give directions, give a song), or through a relation that makes the recipient, medium or destination clear.

Keep the source's boundary example: sending a letter to a newspaper can remain “send a letter to the paper”. The lesson must not teach that every ordinary verb requires replacement.

#### 3. A short cross-topic contrast: show

Keep the source's show examples together in one compact comparison panel because the same ordinary word changes meaning:

- make an effect clear;
- let someone see pictures / put them on view;
- take someone round to see old buildings;
- give signs of interest.

“Try to show interest” demonstrates the named-attempt pattern. It is a supporting example, not a separate topic.

This panel is a **polysemy comparison**, not a claim that all show meanings are communication. Link “show interest” to C06 and the knowledge/clarity uses to C05 where appropriate.

#### 4. Guided practice

For each prompt, ask the learner to identify the actual event before choosing the Basic expression:

1. Is someone expressing, receiving, recording or sending information?
2. Who is the receiver, and what is the medium or destination?
3. Does the context mean communication, knowledge, display, guidance or signs of an attitude?

Include one prompt where the ordinary word itself remains usable in Basic, so the learner does not over-rewrite.

#### 5. Reverse check

Give a Basic expression and ask what communication event it describes. The learner must distinguish, for example, hearing sound from giving attention to it, and reading information from sending it.

### Scope controls

- “Speak a language” cross-links to C05/C09; do not teach it as ordinary speaking to another person.
- All show senses appear together only as a short comparison panel; their meanings are not forced into the communication category.
- “Try” remains the attempt pattern inside the show-interest example.
- Do not reteach the 16 Operators or Names of Acts foundation.

### Lesson-size test

**Current judgment:** one Lesson remains viable if the communication examples are taught in three compact role groups and show is kept to one comparison panel. If show expands into a full separate topic, it will overload C01 and must remain a cross-reference instead.

## C02 — Bodily Action & Contact

### Teaching objective

The learner identifies the physical action being described and makes the relevant body/object relation explicit. Keep the two source groups visible rather than pretending eating and touching are the same action.

### Proposed teaching flow

#### 1. Taking in, biting and putting out

Use eat, bite and spit:

- taking food / having a meal;
- having a bite of something;
- putting food out of the mouth.

Ask what the body is doing to or with the object. Show that Basic may name the action (a bite/meal) or make the direction/body location explicit (out of the mouth).

#### 2. Contact, impact and rubbing

Use touch, accidental contact, hit and scratch:

- putting a hand/finger/body part on something;
- coming up against something by chance;
- giving a blow;
- making a mark, giving a rub or getting nails into something.

The learner must distinguish simple contact, accidental contact, force, and the effect of scratching. Do not treat all of these as synonyms.

#### 3. Guided practice

Use two labelled groups of prompts:

- **Bodily intake/expulsion:** What enters, is bitten, or is put out?
- **Contact/impact:** What touches what? Is the contact accidental, forceful, or does it leave a mark?

Ask the learner to identify the action and relevant body/object relation before constructing the Basic expression.

#### 4. Reverse check

Give the Basic expression and ask whether it describes intake, biting, expulsion, contact, impact or rubbing.

### Scope controls

- C02 teaches the action itself, not the resulting damage or state; those belong in C03.
- Keep hurt/damage and cut/break/smash results in C03.
- Do not repeat the general Operator + Name construction lesson.

### Lesson-size test

**Current judgment:** one Lesson with two explicit parts is viable. Both parts train the learner to express a bodily action by making the acted-on object and body relation clear. The sections should remain separate inside the Lesson.

## C03 — Physical Effects: Damage, Change & Result

### Teaching objective

The learner distinguishes:
- an action that causes a physical change;
- the effect/damage produced;
- the resulting state;
- a change that occurs without an external agent being stated.

### Prerequisite

Use the current App's Step 17, sections 4–6, as the foundation reference for past participles, be + past participle, and get + past participle. C03 gives only a short reminder with its own examples; it does not reteach the full passive/get-passive system.

### Proposed teaching flow

#### 1. Start with a physical action and its result

Use cut and break to compare:

- the action or act of cutting;
- something being cut;
- an object being broken;
- an object being got broken / made to enter the broken state.

Ask: is the sentence describing what someone does, what happens to the object, or the state the object is in afterward?

#### 2. Compare damage and destruction

Use smash, destroy and hurt:

- breaking or smashing an object;
- causing a physical result;
- giving someone pain, wounds or damage.

Do not turn hurt into a generic synonym for hit: C02 can describe the contact/impact; C03 describes the injury or effect.

#### 3. Include self-occurring change

Use the source's plate example: when the plate breaks by itself, the expression describes its coming to pieces. No agent needs to be introduced.

This contrast is important:
- caused action;
- passive/result state;
- self-occurring change.

#### 4. Guided practice

For each prompt, ask the learner to classify the intended meaning before writing:

1. What action causes the change?
2. What physical effect occurs?
3. What is the resulting state?
4. Does the sentence state an agent, or does the change happen by itself?

Link back to Step 17 if the learner cannot form the required participle/passive pattern.

#### 5. Reverse check

Give a result expression and ask what physical event or state it describes. Check that the learner does not invent an agent when the source sentence does not state one.

### Scope controls

- C02 covers contact/impact as an action; C03 covers the physical effect/result.
- C03 does not teach the full passive or get-passive rule; Step 17 is the prerequisite.
- Do not confuse -ed word formation with passive/result sentence structure.
- Keep non-physical emotional effects in C06 unless the source example is specifically physical damage.

### Lesson-size test

**Current judgment:** one Lesson is justified. Cut, break, smash, destroy and hurt are connected by the physical-change/effect decision. The caused-action/result/self-occurring contrasts provide a natural teaching progression and prevent the lesson from becoming a list of replacement phrases.

## C04 — Movement & Position: Transfer, Posture & Viewpoint

### Teaching objective

The learner identifies what or who changes place, the path/destination or position involved, and whose viewpoint determines the expression.

### Proposed teaching flow

#### 1. Moving an object

Start with throw, catch and hold:

- sending an object to a receiver or along a path;
- getting it into the hand;
- having or keeping a grip on it.

Ask: does the object move to a destination, arrive at a position, or remain held?

#### 2. Direction and viewpoint

Use bring/take and come/go contrasts:

- the same movement can be described differently depending on the speaker's reference point;
- destination and path can be stated with the relevant Directives;
- bring/take should not be taught as a fixed Chinese translation pair.

Use the source's examples of sending something over a wall/across a river and moving an arm out of a coat or money into a pocket.

#### 3. Body position and posture change

Compare:

- being in a position;
- moving into a position;
- taking a seat / being seated;
- getting up.

The learner must distinguish a state from the action that changes the state.

#### 4. Run and slip as meaning contrasts

Keep run's different uses together as a short contrast:

- speed of movement → go quickly;
- an activity undertaken for health → take a run;
- escaping at a run → go (off) at a run.

Keep slip's source uses together as a small contrast:

- losing one's footing on ice → have a slip / have a fall;
- a quick, simple action → take your arm out of your coat; put money into your pocket; go quickly out of the house.

These are source examples, not a general rule that every quick action is called a slip.

#### 5. Supporting position changes

Keep two further examples brief:

- a sudden noise may throw or put us off our balance;
- a blow, given hard enough, will send us violently against the table.

The first describes a change in balance; the second describes movement to a position. The physical blow itself remains cross-linked to C02.

#### 6. Guided practice and reverse check

Ask the learner to identify:
1. the moving person/object;
2. the starting point, destination or path;
3. the reference viewpoint;
4. whether the sentence describes movement or a position/state.

Then give Basic expressions and ask the learner to reconstruct the movement or posture.

### Scope controls

- C04 applies Directives and source/destination tools; it does not reteach them.
- Physical contact/impact belongs to C02; physical damage/result belongs to C03.
- Keep state vs posture change explicit, but do not create a separate Lesson just for sit/stand/lie.

### Lesson-size test

**Current judgment:** one Lesson remains viable with two main sections — object transfer/viewpoint and body position/posture — plus short run/slip contrasts. The common task is to make movement, path, destination and position explicit.

## C05 — Thinking, Knowledge, Memory & Learning

### Teaching objective

The learner identifies the mental operation or relation intended — thinking, opinion, certainty, understanding, meaning, memory, or acquisition/transfer of knowledge — and expresses that relation in Basic.

### Proposed teaching flow

#### 1. Thinking and opinion

Compare:
- having/giving thought;
- holding an opinion;
- taking a view.

The learner first decides whether the sentence describes a mental activity or a stated judgment.

#### 2. Knowing and understanding

Compare:
- being certain or conscious of something;
- having knowledge or experience of it;
- familiarity with a person: being a friend of theirs / having come across them; the source also uses come across for books, pictures and other things seen;
- being clear about it / having a grip of it;
- seeing another person's point of view or the point of an argument.

The point is not to teach these as interchangeable phrases. Each expresses a different degree or kind of mental relation.

#### 3. Meaning and memory

Use:
- having the sense of something;
- having a memory of it;
- keeping it in mind;
- putting it out of the mind / having no memory of it.

Contrast keeping a thought available with the absence/removal of memory.

#### 4. Learning and teaching

Add the acquisition/transfer perspective:

- getting facts or knowledge into one's head;
- giving training/teaching;
- being taught.

This belongs here because the learner is still expressing how knowledge is acquired or transferred, rather than how information is communicated to an audience.

#### 5. Guided practice

For each prompt, ask:
1. Is this thinking, judging, knowing, understanding, remembering, forgetting, learning or teaching?
2. Is the Basic expression a state, a mental activity, possession of knowledge, or transfer/acquisition?
3. Which Name/Quality/Operator/Directive relation carries the meaning?

Include contrasts such as “know a fact” vs “understand an argument” and “remember” vs “keep in mind”.

#### 6. Reverse check

Give the Basic expression and ask what mental relation it expresses. Reject answers that flatten certainty, opinion, understanding and memory into one generic “know”.

### Scope controls

- C05 is about mental knowledge and cognition; C06 is about feeling, preference and desire.
- “Speak a language” cross-links here because it means having knowledge of a language, not simply speaking to someone.
- “Show interest” remains in C01's short show comparison, with a cross-link to C06; do not duplicate it here.
- Names of Things/Qualities expansion is taught in Module 1 and referenced where it helps explain expressions such as mind, grip and point of view.

### Lesson-size test

**Current judgment:** one Lesson is viable. The four sections are different stages of the same broad mental-knowledge task: form a thought, hold/judge knowledge, retain/lose it, and acquire/transfer it.

## C06 — Feeling, Preference, Desire & Need

### Teaching objective

The learner distinguishes an internal experience, an attitude toward something, a preference, a desire and a need. The Basic expression should make the relevant relation clear rather than treating feel/like/want/need as one-word replacements.

### Proposed teaching flow

#### 1. Feeling and experience

Use pain, pleasure, a feeling that something is so, and feeling angry.

Ask whether the sentence describes:
- a feeling as an experience;
- an idea or impression;
- a Quality/state.

Keep the physical use of feel — touching a wall to test it — as a cross-link to C02, not as part of the internal-feeling rule.

#### 2. Liking and approval

Compare:
- being pleased with something;
- having or giving approval, or being in agreement with something;
- giving disapproval, or being in disagreement with something;
- getting on well with a person / being friends with them;
- having a taste for food or pictures.

The learner must identify whether the sentence is about being pleased with a thing, being friends with a person, approval or taste.

#### 3. Desire and need

Compare:
- having a desire for something;
- being in need of something;
- needing more because the available amount is insufficient.

The learner should distinguish wanting from a need arising from circumstances.

#### 4. Guided practice

Use short contexts where the ordinary verb is ambiguous:
- like a person vs like a picture;
- feel pain vs feel that something is true;
- want something vs need more of it.

Require the learner to state the intended relation before choosing the Basic expression.

#### 5. Reverse check

Give the Basic expression and ask whether it describes an experience, attitude, preference, desire or need.

### Scope controls

- C06 does not absorb C05's knowledge/understanding meanings.
- Physical touch belongs to C02.
- Show interest remains in C01's comparison panel, with a cross-link to attitude/feeling here.
- Do not treat desire and need as identical.

### Lesson-size test

**Current judgment:** one Lesson is viable. The examples form a progression from internal experience to attitude/preference and then desire/need. The same ordinary words have several senses, so context comparison is essential.

## C07 — Exchange, Sale & Commitment

### Teaching objective

The learner describes a transaction by identifying what is exchanged, who gives or receives value, and whether the expression describes a sale, payment, keeping goods for sale or a commitment.

### Proposed teaching flow

#### 1. Understand the exchange

Start with buy and sell as two viewpoints of a transaction:

- the buyer gets the thing in exchange for money / gives money for it;
- the seller gets money for what is given.

Ask the learner to identify the object, the money/value, and each participant's role before choosing the Basic expression.

#### 2. Extend to sale arrangements

Use the source examples of:
- keeping goods in a store for sale;
- putting what is made on the market.

These are not simply “buy/sell” synonyms. They describe preparing or offering goods for a transaction.

#### 3. Express commitment

Use the promise-to-pay-later example:

- giving one's word;
- the action the person commits to do.

Contrast an actual exchange with a promise about a future exchange. The learner must not treat a promise as if payment has already happened.

#### 4. Fixed-group reinforcement

Select only the fixed uses that naturally reinforce the transaction/commitment theme, such as agreement, letting a house, exchange, carrying an undertaking through, money risk, approval, credit, profit/loss, demand, company participation and keeping one's word.

Do not import unrelated social or emotional phrases merely to make the lesson longer.

#### 5. Guided practice and reverse check

For each context, ask:
1. Is this an exchange, sale arrangement, payment/credit, financial risk or promise?
2. Who gives what, and who gets what?
3. Has the transaction happened, or is it only promised/planned?

Then give Basic expressions and ask the learner to reconstruct the transaction roles.

### Scope controls

- C07 covers exchange and commercial commitment, not general feelings about people; those belong to C06.
- Fixed Word-Groups are selected reinforcement, not a second 50-item vocabulary lesson.
- Business/legal context examples should not turn C07 into a general law or social-relations course.

### Lesson-size test

**Current judgment:** one compact but coherent Lesson is justified. The direct Some Common Needs material is small, but the complete fixed-group index adds a meaningful cluster of transaction, credit, agreement and commitment uses. The lesson should remain focused and use selected examples rather than attempting to teach every business-related fixed phrase.

## C08 — State and Process: Change, Entry & Ending

### Teaching objective

The learner distinguishes a state, entering a state, a process that is under way, and the beginning or ending of a process.

### Proposed teaching flow

#### 1. Change into a Quality or state

Use grow:

- getting taller, higher, fatter or greater;
- being in the process of growth/development.

Show the difference between the resulting Quality and the process that produces it.

#### 2. Entering or being in a state

Use sleep:

- going to sleep;
- being in sleep.

The learner distinguishes the change into the state from the state itself.

#### 3. Life process and ending

Use die as a contrast set:
- going to one's death;
- coming to one's end;
- taking one's last breath.

These expressions describe the end of a life process from different viewpoints. Do not turn them into three unrelated rules.

#### 4. Beginning and finishing

Use begin → make a start, and preserve the source's important boundary that finish can itself be used in Basic.

The learner must not assume every ordinary verb needs to be replaced.

#### 5. Fixed-group reinforcement

Use a small set of naturally related fixed groups:
- being in motion / in use;
- coming to a stop;
- going to sleep;
- something happening in the end;
- an event taking place;
- putting a stop to an activity.

These reinforce state, occurrence and cessation.

#### 6. Guided practice and reverse check

Ask:
1. Is the sentence describing a state or a change into it?
2. Is a process continuing, beginning or ending?
3. Does the Basic expression describe the event, its state or its result?

### Scope controls

- C08 does not cover physical damage/result; that belongs to C03.
- C08 does not cover spatial movement/path; that belongs to C04.
- C08 does not teach modal intention or obligation; that belongs to C09.
- Preserve the source's use of finish without forced replacement.

### Lesson-size test

**Current judgment:** one Lesson is viable. Growth, sleep, death, beginning and ending share the state/process decision, and the fixed groups reinforce the same theme.

## C09 — Ability, Obligation & Intention

### Teaching objective

The learner identifies whether the sentence expresses ability, possibility, duty, advisability, probability or intention, and chooses the Basic construction that preserves that specific force.

### Proposed teaching flow

#### 1. can: ability and possibility

Compare:
- a person is able to do something;
- something is possible for a person.

Do not reduce both to a single Chinese gloss without checking whether the sentence describes a person's capacity or the possibility of an event.

#### 2. ought: several distinct meanings

Teach the source's contrasts explicitly:

- what is right or wise for someone to do;
- what is someone's business/duty;
- what is probable from the facts.

These are not interchangeable. The learner must identify whether the sentence is advice, obligation or an expectation based on evidence.

#### 3. shall: statement vs question

- In a statement, shall is expressed with will.
- In “Shall I ...?”, the question can ask whether the speaker is going to do it, or whether doing it is wise.

Do not teach shall as a single future-tense translation in every sentence.

#### 4. Fixed-group reinforcement

Use “be able to” as a priority fixed group. “Have to” can be used as a related contrast when the sentence expresses necessity, but do not claim it is a direct replacement for every ought meaning.

#### 5. Guided practice

For every prompt, require the learner to label the intended force first:

- ability;
- possibility;
- duty;
- advice/wisdom;
- probability from facts;
- intention.

Then construct the Basic expression.

#### 6. Reverse check

Give a Basic sentence and ask whether it expresses capacity, possibility, duty, advice, probability or intention. Reject an answer that preserves only the rough topic but changes the speaker's stance.

### Scope controls

- C09 is self-contained for the source's can/ought/shall distinctions; it assumes only the existing sentence/Operator/infinitive foundation.
- unless → if ... not belongs to conditional sentence structure, not this Lesson.
- Do not assume unadapted Step 21/22 auxiliary content is available in the local App.
- Keep ability distinct from obligation, and intention distinct from prediction.

### Lesson-size test

**Current judgment:** one Lesson is justified. The three source words have different meanings, but they share one learner decision: identify the speaker's stance toward an action or event. The internal sections prevent them from being flattened into one “modal” rule.

## C10 — Quantity, Amount & Degree

### Teaching objective

The learner distinguishes number/amount, distribution, totality and degree. The learner also recognizes that a short word such as too can express different relations in different contexts.

### Proposed teaching flow

#### 1. Distribution and totality

Compare:
- each: members considered separately;
- altogether: the total amount, or in some contexts completely;
- whole: the group taken as one complete unit.

Use examples that make the difference visible: one-by-one vs total count vs the complete group.

#### 2. Small and large amounts

Compare:
- few: a small number;
- many: a large number.

Keep the source's warning: when the exact amount matters, use a more explicit expression rather than relying on an unclear vague quantity.

#### 3. too: amount, degree or addition

Teach the source's distinct uses separately:

- too many: more than enough;
- too tired to go: degree so high that it prevents an action;
- ill too: another/additional condition.

Do not teach too as a single translation.

#### 4. once: quantity or time

- once = one time only belongs here;
- once = at one time / in the past cross-links to C11.

#### 5. Guided practice and reverse check

Ask:
1. Is the sentence counting separately, giving a total, or describing a whole?
2. Is the amount small/large?
3. Does too mean excess, disabling degree or addition?
4. Does once mean one occurrence or a past period?

Then give Basic expressions and ask the learner to reconstruct the quantity/degree relation.

### Scope controls

- Basic counting and number expressions are already in the 45-Step foundation; C10 teaches the source's additional contextual uses.
- Time senses of once move to C11.
- next to is spatial adjacency and cross-links to C04, not a time expression.
- Do not treat all uses of too as quantity.

### Lesson-size test

**Current judgment:** one Lesson is viable if the three uses of too and the two uses of once are taught as explicit contrasts. The common decision is how much, how many, how completely, or to what degree something applies.

## C11 — Time & Sequence

### Teaching objective

The learner identifies the exact time relation: how long ago, whether something has happened by now, whether it has not happened yet, what point a period starts from, what comes next, whether something repeats, or whether it continues always.

### Proposed teaching flow

#### 1. Past time and time up to now

Compare:
- ago / a long time back;
- already / before;
- so far / up to now;
- yet in a negative sentence.

The learner must identify the reference point: a past time, the present moment, or the period continuing to the present.

#### 2. since: time or reason

Teach two different relations:
- since as a time starting point;
- since as a reason, equivalent to because.

The reason use cross-links to the sentence relation foundation; do not force it into the time rule.

#### 3. next: sequence, repetition or position

Compare:
- next = after this;
- next = do the same thing again on the next occasion;
- next to = nearest/beside something.

The last is spatial and cross-links to C04.

#### 4. always: frequency or continuation

Compare:
- at all times;
- frequently in the source's relevant context;
- for ever when future continuation is emphasized.

Do not teach always as one fixed frequency word.

#### 5. Guided practice and reverse check

For each sentence, ask:
1. What is the reference time?
2. Is the relation past, up to now, not yet, starting point, reason, sequence, repetition, adjacency or continuation?
3. Which part of the sentence proves that reading?

Then give the Basic expression and ask the learner to recover the time relation.

### Scope controls

- Calendar, clock and basic tense foundations are not repeated.
- Quantity once = one time only remains in C10; past-time once is handled here.
- Since = because is cross-linked to sentence relations.
- next to is spatial and belongs by cross-link to C04.

### Lesson-size test

**Current judgment:** one Lesson is viable. The items are diverse words, but the learner's task is consistently to identify the time/sequence relation rather than memorize a single translation.

## C12 — Context-Dependent Words & Paraphrase

### Teaching objective

The learner takes an ordinary-English word that is not directly available as a Basic expression, identifies what it means in this particular context, and describes that meaning with Basic words.

### Proposed teaching flow

#### 1. Describe a Quality with Basic words

Use:
- busy → someone working hard / having much to do;
- deaf → someone whose hearing is bad.

Ask what observable condition the ordinary adjective describes, then build a Basic description.

#### 2. Compare different meanings of the same Name

Use world, life, hill, home and address:

- world can refer to the earth, people, or conditions/things, depending on the sentence;
- life can mean existence, living things, or the activity of living;
- hill can require a description based on height/shape/size;
- home refers to the place where a person lives, not automatically a house;
- address can mean a home location, business location or the heading of a letter.

The learner should never memorize a single replacement without the context.

#### 3. Context-first paraphrase method

For every prompt:
1. identify the exact intended meaning in the sentence;
2. ignore the ordinary word temporarily;
3. describe the referent or condition using Basic words;
4. read the Basic description back and check whether it preserves the intended meaning.

#### 4. Guided practice

Use contrast pairs:
- world as earth vs world as people/conditions;
- life as existence vs living things vs the activity of living;
- home vs house;
- personal address vs business address vs letter heading.

Ask the learner to explain why one Basic paraphrase does not fit all contexts.

#### 5. Reverse check

Give a Basic description and ask which context-dependent sense it could represent. Where more than one sense remains possible, the learner must request or use more context rather than guess.

### Scope controls

- C12 starts from an ordinary-English word outside the Basic set and constructs a Basic paraphrase.
- C15 starts from a Basic word and interprets a contextually narrowed use. The direction of the task is different.
- C13/C14 explain how an already-known Basic word can carry a source-recognized related meaning; C12 does not.
- Do not teach busy/deaf as Names of Qualities expansions.

### Lesson-size test

**Current judgment:** one Lesson is viable. The words are diverse, but the common operation is context-first paraphrase: identify the intended sense, then describe it with Basic words. The contrast examples are essential; one-to-one replacement cards would be incorrect.
